## 0.11.0 - 2026-05-19

Feature release focused on streamlining the agent registry and fixing cross-platform compatibility.

### Features

- Streamline built-in agent registry: retain all coding platforms and only keep WorkBuddy and QoderWork from the Lobster category (Hermes, OpenClaw, QClaw, EasyClaw, AutoClaw removed).
- Unify central skills directory path to `~/.agents/skills/` across the entire codebase (Rust backend, frontend stores, i18n).

### Improvements

- Fix SQLite connection string handling on Windows by normalizing backslash paths to forward slashes.
- Fix corrupted PowerShell `$ErrorActionPreference` line in the Windows release workflow.

### Fixes

- Resolve path discrepancy where central skills directory was hardcoded as `~/.trae-cn/skills/` instead of the documented `~/.agents/skills/`.
- Fix Windows database initialization failure caused by backslash path in SQLite URI.

## 0.11.0 - 2026-05-19

聚焦精简智能体注册表和修复跨平台兼容性的功能版本。

### 新功能

- 精简内置智能体注册表：保留所有编程类平台，Lobster 类仅保留 WorkBuddy 和 QoderWork（移除 Hermes、OpenClaw、QClaw、EasyClaw、AutoClaw）。
- 统一中央技能库路径为 `~/.agents/skills/`，覆盖 Rust 后端、前端 Store 和国际化文件。

### 改进

- 修复 Windows 平台 SQLite 连接字符串中反斜杠路径的问题，统一转换为正斜杠。
- 修复 Windows 发布工作流中损坏的 PowerShell `$ErrorActionPreference` 行。

### 修复

- 解决中央技能库路径不一致问题：代码中硬编码为 `~/.trae-cn/skills/`，与文档要求的 `~/.agents/skills/` 不一致。
- 修复 Windows 上因 SQLite URI 中反斜杠路径导致的数据库初始化失败。
